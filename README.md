# Sablon Tools - Script & Action Photoshop

Kumpulan 5 script Photoshop (Auto Raster Studio, Auto Register Spot,
DTF Raster Tools, Layout Film, Buat Channel Kaos) yang terpasang
sebagai tombol di panel Actions.

## Unduh
Buka halaman Releases di sebelah kanan, lalu pilih:
- Windows: SABLON_TOOLS_Setup.exe
- Mac: SABLON_TOOLS_Mac.zip

## Pasang di Windows
Jalankan SABLON_TOOLS_Setup.exe. Alternatif tanpa installer: ekstrak SABLON_TOOLS_Windows.zip, klik kanan Install.bat > Run as administrator. Jika muncul peringatan SmartScreen atau
antivirus, itu karena installer belum bertanda tangan digital. Kode
sumbernya terbuka di repository ini (installer.nsi). Pilih "More info",
lalu "Run anyway".

## Pasang di Mac
Ekstrak zip, klik kanan Install.command, pilih Open. Petunjuk lengkap
ada di BACA_DULU.txt (ada di dalam SABLON_TOOLS_Mac.zip).

## Setelah terpasang
Buka ulang Photoshop > Window > Actions > menu panel > SABLON TOOLS >
Button Mode.

## Copot
Windows: Add/Remove Programs. Mac: klik kanan Uninstall.command > Open.
